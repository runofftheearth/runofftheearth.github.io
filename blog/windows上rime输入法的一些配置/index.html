Windows上Rime输入法的一些配置

2026年 08月 07日 简体中文

中英输入法快捷键修改

老老实实用Ctrl吧，1909在某些软件内Ctrl + 空格不生效。

customization:
  distribution_code_name: Weasel
  distribution_version: 0.17.4
  generator: "Rime::SwitcherSettings"
  modified_time: "Fri Aug  7 15:45:06 2026"
  rime_version: 1.13.1
patch:
  "ascii_composer/switch_key":
    Caps_lock: noop
    Control_L: noop
    "Control_L+space": noop
    Control_L: commit_code
    Shift_R: noop
    Shift_L: noop
  schema_list:
    - {schema: luna_pinyin_simp}
  menu:
    page_size: 7  # 全局候选词个数：7个

要在 Rime（如小狼毫 Weasel 或鼠须管 Squirrel）中修改或使用 Ctrl + 空格 切换中英文，需要处理系统热键冲突并配置 default.custom.yaml 文件。

解决系统快捷键冲突（Windows）

Windows 系统默认用 Ctrl + 空格 作为“中/英输入法切换”或“开关输入法”的全局热键，这会导致 Rime 无法直接截获该按键。

打开 Windows 设置 -> 时间和语言 -> 语言和区域（或高级键盘设置）找到 ->输入语言热键 / 高级键设置。

将“中英文输入法切换”或“开关输入法”的快捷键修改为其他不常用的按键，避免与 Rime 冲突。

配置P站风格配色主题

在rime上右键打开用户文件夹，找到weasel.custom.yaml编辑。

customization:
  distribution_code_name: Weasel
  distribution_version: 0.17.4
  generator: "Weasel::UIStyleSettings"
  modified_time: "Fri Aug  7 15:54:21 2026"
  rime_version: 1.13.1
patch:
  "preset_color_schemes/dodopoi":
    author: "言别离"
    back_color: 0x000000
    border_color: 0x000000
    candidate_text_color: 0xffffff
    comment_text_color: 0xffffff
    hilited_back_color: 0x009bff
    hilited_candidate_back_color: 0x009bff
    hilited_candidate_text_color: 0x000000
    hilited_comment_text_color: 0x000000
    hilited_lable_color: 0x000000
    hilited_text_color: 0x000000
    label_color: 0xffffff
    name: dodopoi
    text_color: 0xffffff
  "style/color_scheme": dodopoi  # 配色方案
  "style/horizontal": true  # 启用候选框横版显示
  "style/inline_preedit": true  # 在输入框中显示预编辑
  "style/candidate_spacing": 10  # 候选词间距（单位：像素）
  "style/font_point": 13  # 候选字大小（单位：磅）
  "style/label_font_point": 11  # 标签字大小（单位：磅）
  "style/comment_font_point": 11  # 注释字大小（单位：磅）
